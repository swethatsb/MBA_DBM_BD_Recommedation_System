# E-Commerce Recommendation System

## Project Overview

This project is an e-commerce recommendation system built using Amazon product review and metadata.

The system recommends products using multiple recommendation approaches including:

- Popularity-based recommendation
- Content-based recommendation
- Collaborative filtering
- Hybrid recommendation

## Dataset

The project uses processed Amazon review and product metadata from 10 product categories.

The dataset is not included in this repository because of its large size.

## Technologies Used

- Python
- Google Colab
- Pandas
- DuckDB
- PyArrow
- Scikit-learn
- Implicit
- Streamlit
- GitHub
